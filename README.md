# SmPlan: ToDo List With Reminder

## 📌 Description

SmPlan is a productivity-focused ToDo and reminder application designed to help users manage daily tasks efficiently. It includes features like Pomodoro-based task timing, custom reminders, analytics, streak tracking, and a clean user interface to improve focus and reduce distractions.

## 🛠 Technologies Used

* **React.js** – UI development
* **Recharts** – Data visualization for ratings and analytics
* **Tailwind CSS** – Styling and responsive layouts
* **React Router** – Navigation between screens
* **JavaScript (ES6+)** – Core logic and functionality
